# 🍽️ Campus Bite – Food Ordering App (Flutter)

Campus Bite is a cross-platform mobile application developed using **Flutter**.  
It enables students to browse menus, add items to cart, place orders, and make seamless payments within the college premises.

---

## 📌 Project Overview

Campus Bite is designed to solve common issues faced by students in college cafeterias such as:

- Long waiting queues  
- Limited break time  
- Slow manual order processing  
- Inefficient order management  

The app allows users to **pre-order food**, **view menus**, **add items to a cart**, and **make payments** via QR codes.

---

## 🚀 Features

### 🔐 Authentication
- Welcome screen  
- Sign in & Sign up pages  
- Form validation (Email, Password rules)  
- Drawer menu navigation  

### 🧾 Menu Browsing
- View categorized menus (Fast food, Tiffins, Juice, Pani Puri & Chats)  
- Search bar to filter items  
- Item cards with image, name, and price  
- "Add to Cart" functionality  

### 🛒 Cart Management
- Increment/decrement item quantity  
- Grouping items by restaurant category  
- Automatic subtotal calculation  
- Remove item option  

### 💳 Payment
- Display QR codes for each category subtotal  
- Total payable calculation
